# Security policy

Please do not report a vulnerability in a public issue.
Report it privately through GitHub: [report a vulnerability](https://github.com/lodia-io/cluster-api-provider-lodia/security/advisories/new).

Include what is affected (the provider's version, the Cluster API version and Lodia's commit), how to reproduce it and the impact you see.
We confirm receipt, agree on a disclosure date with you, and publish the fix with a GitHub security advisory.
